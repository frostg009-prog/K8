# Проверка стыковки (06.11): хвост v10 + серво MG90S + трубки (из вашей сборки) + элероны + большие крылья + рамы + Tail Mount + нос

Положение крыльев, рам, Tail Mount, держателей — из вашего STEP в сборе (старая версия); трубки — из вашей новой сборки (4 шт, Ø6×4, длина ≈206 мм).

| Стык | Результат |
|---|---|
| Серво ↔ хвост | 0 мм³ (все 4), вставка снаружи без задеваний |
| Вал серво ↔ трубка | ось трубки = ось вала; конец трубки на шлицах (нужен переходник: шлиц Ø4,9 > внутр. Ø4) |
| Трубка ↔ элерон | ось трубки = ось канала элерона (0,00 мм, 0,00°), трубка проходит канал Ø6,2 по всей длине |
| Трубка ↔ крыло | трубка входит в отверстие Ø6,2 в боковом торце крыла: угол 0,00°, смещение 0,12 мм — плотно, рекомендую Ø6,4 |
| Трубка ↔ хвост | 0 |
| Элерон ↔ хвост | зазор 7,7 мм на всём ходе |
| Элерон ↔ крыло | свободно до ±18°; ±20° — 1–3 мм³, ±30° — 25–30 мм³ (задевает) |
| Хвост ↔ Tail Mount / рамы / панели / крылья | 0 |
| Нос ↔ рамы | 0 |
