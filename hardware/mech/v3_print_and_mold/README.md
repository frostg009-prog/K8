# Нос и хвост: версия для печати (1 деталь) и для литья (2 детали)

| Деталь | Печать | Литьё |
|---|---|---|
| Хвост | `print/tail_print.step/.stl` — 1 деталь, полая, без центрального креста | `mold/tail_mold_halfA/B` — 2 половины, плоскость разъёма под 45° к осям (проходит через щели упругих сегментов, сегменты не режутся) |
| Нос | `print/nose_print.step` (с зацепами), `nose_print_nohooks.step` (без) | `mold/nose_mold_halfA/B` — 2 половины по плоскости X=0 (из версии без зацепов) |
| Крыло | одна деталь (файла крыла нет — прислать) | две детали (то же правило) |

Важно (честно): половины — чистое деление тела плоскостью. Не добавлено: штифты/пазы совмещения, уклоны ≥1°, фиксация
фланцем/винтами — их задаёт конструктор оснастки Промолда (или добавляется операцией Draft в CAD). В половинах носа остаются
по 2 отдельных острова (кронштейны), которые держатся за вторую половину — Промолд должен решить, как их сидеть.
Хвост: в версии для печати стенка конуса 2,0 мм; для литья рекомендуется 2,0–2,5 мм с рёбрами жёсткости у разъёма.
