# Проверка сборки: хвост v5 + серво MG90S + карбоновая трубка Ø6×4 + элерон (расчёт по вашим STEP)

| Проверка | Результат |
|---|---|
| Серво в кармане хвоста | зазор 0,25 мм, пересечение 0 мм³; серво вставляется снаружи по радиусу через окно 13,6×34,1 мм (прогон 30→0 мм без столкновений) |
| Серво ровно | ось вала ⟂ оси хвоста (убран наклон 7,5°), ось вала z=196,2 мм |
| Ось вала = ось канала в элероне | совпадают (смещение 0,00 / 0,01 мм) после выравнивания элерона вместе с серво |
| Трубка Ø6 в канале элерона Ø6,2 | вмещается, зазор 0,1 мм на сторону — для FDM-печати тесно, рекомендую канал Ø6,4 |
| Трубка в окне/щели хвоста | пересечения нет |
| Вал серво Ø4,9 (шлицы) и трубка Ø6×Ø4 | **не стыкуются напрямую**: внутренний Ø4,0 < Ø4,9. Нужен переходник (втулка со шлицевым гнездом Ø4,9 и хвостовиком под трубку), как чёрный наконечник на вашем фото |
| Корень элерона и хвост | **было**: корень (x 22–31 мм, z 218–240) входил в конус хвоста на 0,2 см³ (мешал бы вращению). **Исправлено**: корень подрезан по огибающей хвоста для отклонения ±30° с зазором 0,5 мм; остаточные пересечения ≤5 мм³ (заусенцы <0,1 мм) на ±15…30° |
| Элерон и серво | пересечения нет |
| Провода серво | в модели серво проводов нет; место у внутреннего торца серво и центральная полость для них оставлены; точное место выхода провода проверить на реальном серво |
| Длина трубки | от Ø-переходника (x≈34 мм от оси) до конца канала в элероне (x≈234 мм): ≈200 мм |

«Крыло» в ваших файлах = элерон (`Элерон_подрезка_1.59 мм.STEP`); отдельной модели крыла нет.
