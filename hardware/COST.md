# Себестоимость (оценка на ноябрь 2026)

Детали платы посчитаны по **живым ценам JLCPCB/LCSC** с ценовыми ступенями (`kicad/cost.py` → `docs/BOM_cost.csv`, 85 позиций, всё в наличии).
Изготовление плат и монтаж — по прайсам JLCPCB и Резонита. Это оценка: перед заказом пересчитайте в калькуляторах заводов.

Вывод: при 10 000 шт вариант В экономит не больше ≈ $10–20 на плате по сравнению с готовым модулем RK3576 (вариант Б).
Разработка с нуля отбивается только на десятках тысяч штук и несёт риск. Поэтому рекомендуется вариант Б (или А для максимальной совместимости с BirdWatch).
