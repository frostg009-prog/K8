# Заказ на заводе: Резонит (Россия) и JLCPCB (Китай)

## Параметры платы (одинаковые для обоих заводов)
| Параметр | Значение |
|---|---|
| Размер | 44 × 134 мм, 1 плата (без мультиплицирования; для серии — панель 2×3 с перемычками) |
| Слои | 4: F.Cu (сигналы, детали) / In1 GND / In2 GND + полигоны +5V_CM5, +5V_AUX, VIN / B.Cu (сигналы, детали) |
| Толщина | 1,5 мм; стек **Резонит «4 Layers (1,5mm 18um Tg150 Impedance)»**: препрег 0,127 мм εr 4,2 / ядро 1,2 мм εr 4,6 |
| Медь | наружные 18 мкм + металлизация (~35–45 мкм итог), внутренние 18 мкм (или 35 мкм — улучшает теплоотвод) |
| Материал | FR-4 Tg150 |
| Мин. дорожка / зазор | 0,1 / 0,1 мм у разъёма CM5, остальное ≥ 0,13 / 0,125 мм (Резонит 5 класс точности; JLC стандарт) |
| Переходные | 0,45 / 0,2 мм (сигнальные), 0,6 / 0,3 мм (силовые); заполнение не требуется |
| Покрытие | ENIG (иммерсионное золото) — обязательно: шаг 0,4 мм у разъёмов CM5 |
| Маска / шелкография | зелёная / белая, с двух сторон |
| **Контроль импеданса** | да: дифф. 100 Ом (камеры MIPI, PCIe) — 0,13/0,17 мм; дифф. 90 Ом (USB) — 0,17/0,15 мм на L1/L4 к L2/L3. Завод корректирует ширину ±10 % |
| Тестирование | электроконтроль 100 % |

Расчёт импеданса: `kicad/impedance.py` (IPC-2141A по стеку Резонита из присланного файла): 0,13/0,17 мм → 99 Ом; 0,15/0,15 мм → 91 Ом.

## Что отправлять
* `04_Gerber/CM5-DETECT_rev03_gerber.zip` — Gerber RS-274X2 + Excellon (PTH/NPTH раздельно) + карта сверловки.
* `04_Gerber/BOM_JLCPCB.csv` и `CPL_JLCPCB.csv` — для монтажа на JLC (коды LCSC). Для Резонита те же файлы + `positions_kicad.csv`.
* Монтаж двусторонний: SMD с двух сторон + THT (XT60, суперконденсаторы, USB-C с выводами крепления) — селективная или ручная пайка.
* Не монтировать (DNP): XT30 (если заказываете XT60), перемычки JP_* остаются разомкнутыми.
* Модуль CM5 и радиатор ставятся после монтажа (вставить, 4 винта M2.5 × 4 мм + стойки 1,5 мм не нужны — модуль сидит на разъёмах).

## Резонит
* Заказ плат: онлайн-калькулятор «Многослойные ПП», 4 слоя, Tg150, 1,5 мм, импеданс — «по стеку заказчика (их же стек)».
* Монтаж: Резонит выполняет SMD-монтаж с двух сторон; компоненты — свои (по BOM, закупка через их снабжение / ChipDip / LCSC) или давальческие.
* Китайские компоненты из BOM доступны в РФ через LCSC (доставка 2–3 недели), ChipDip, Элитан, AliExpress; модуль CM5 — параллельный импорт.

## JLCPCB
* PCB: 4 Layers, 1.6 мм → выбрать 1.5 мм не всегда возможно: используйте 1.6 мм и стек JLC04161H-3313 (препрег 0,1 мм) —
  импеданс пересчитает JLC по заданным 100/90 Ом (Impedance Control: Yes). Механически CM5 не зависит от 0,1 мм толщины.
* PCBA: Assembly side Both, Standard PCBA, загрузить BOM/CPL. Все позиции BOM — коды LCSC, проверены на складе (11.2026).

## Сверка с технологическими возможностями Резонита (rezonit.ru, ноябрь 2026)
| Параметр платы | Значение у нас | Класс Резонита |
|---|---|---|
| Проводник / зазор, медь 18 мкм | 0,10 / 0,10 мм у разъёмов CM5, остальное ≥ 0,13 / 0,125 мм | **продвинутый** (≥0,100), коэффициент цены ×1,5 |
| Полигон ↔ остальная топология (18 мкм) | 0,15 мм | продвинутый (базовый 0,20) |
| Переходное отверстие | сверло 0,20 мм, площадка 0,45 мм (поясок 0,125) | продвинутый (сверло ≥0,2, поясок ≥0,1) |
| Поясок монтажной площадки | ≥ 0,15 мм | продвинутый |
| Отступ внутренних слоёв от металлизированного отверстия | 0,25 мм | норма 0,25 |
| Неметаллизированные отверстия | ≥ 0,5 мм, отступ меди ≥ 0,2 | норма |
| Отступ меди от края (фрезеровка) | 0,3 мм | норма (≥0,25) |
| Шелкография | линия ≥ 0,15 мм, высота шрифта **1,0 мм** | норма (мин. 1,0 мм) |

Вывод: плата укладывается в «продвинутый» класс Резонита (цена платы ×1,5, срок стандартный). Если нужен «базовый» класс, потребуется увеличить плату под зазор 0,125 мм и переходные Ø0,3/0,6 мм; у разъёма CM5 (шаг 0,4 мм) это без доработки разводки невозможно.
Бланк заказа Резонита заполнен: `REZONIT_blank_zakaza_CM5-DETECT_rev0.3_filled.xlsx` (поля проверить в Excel: выпадающие списки заполнены вручную).
