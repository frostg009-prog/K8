# Нос и хвост: печать (1 деталь) и литьё (2 половины)

**Хвост** (исправлено по замечанию): внутри сохранены блок с 4 карманами под сервоприводы MG90S, упругие сегменты, щели и
конус. Удалены ТОЛЬКО центральные стенки (крестообразная перемычка между 4 карманами): сквозной квадратный проём 17×17 мм
(скругление R1) от торца гнезда z=184 до z=215,5 мм. Объём: −6 см³ из 145. Провода серв проходят через центр.
Скрипт: `source/tail_v3.py`.

| Деталь | Печать | Литьё |
|---|---|---|
| Хвост | `print/tail_print.step/.stl` | `mold/tail_mold_halfA/B` — разъём плоскостью под 45° через ось (по двум диагональным карманам) |
| Нос | `print/nose_print.step` (с зацепами), `nose_print_nohooks.step` | `mold/nose_mold_halfA/B` — разъём X=0 (из версии без зацепов) |

Фото деталей: `photos/`. Деление — чистое рассечение плоскостью (сумма объёмов половин = объёму целого, проверено); штифты
совмещения и уклоны ≥1° добавляет конструктор оснастки.
