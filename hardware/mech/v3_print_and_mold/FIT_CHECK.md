# Проверка (хвост v6 + серво MG90S + трубка Ø6 + элерон), по вашим последним STEP

| Проверка | Результат |
|---|---|
| Серво в кармане хвоста v6 | пересечение 0 мм³ у всех 4 |
| Вставка серво снаружи вдоль оси вала (шаг 1,5 мм, 40→0 мм) | столкновений нет |
| Ось вала серво ↔ ось канала в элероне | совпадают (0,0 мм) при вашей посадке серво (наклон 7,5° сохранён) |
| Трубка Ø6 в канале элерона Ø6,2 | вмещается, зазор 0,1 мм на сторону (для FDM лучше канал Ø6,4) |
| Элерон ↔ хвост | зазор 0,9 мм, поворот ±40° вокруг трубки без столкновений |
| Вал серво Ø4,9 ↔ трубка Ø6×4 | напрямую не стыкуется (внутр. Ø4 < Ø4,9): нужен переходник |
| Трубка входит в торец элерона | да: канал открыт на корневом торце (x≈34 мм от оси) и сквозной на другом конце (x≈234) |
| Большое крыло (STL из набора) | отверстие/паз под трубку в нём найти не удалось (нет круглых сечений Ø6…7); без модели посадки крыла проверить нельзя |
